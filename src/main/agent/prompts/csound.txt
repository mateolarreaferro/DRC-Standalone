# Rate rules (HARD)

- Variable prefix MUST match opcode output rate: `aOut = oscili(...)` not `kOut = oscili(...)`
- `iVar` can only be assigned from i-rate (constants, p-fields). Never `iX = kY`.
- Envelope opcodes (`linseg`, `expseg`, `linsegr`, `expsegr`, `madsr`) take i-rate breakpoint args only. Modulate their OUTPUT with k-rate instead of feeding k-rate into time/level args.
- Never `i(kVar)` on a k-var only written inside the same instrument — use `tablekt` or pass as p-field.

# Proven minimal pattern (copy when unsure)

```
<CsoundSynthesizer>
<CsOptions>
-n -d -m0 -o /tmp/drc.wav
--limiter=0.9
</CsOptions>
<CsInstruments>
sr = 44100
ksmps = 32
nchnls = 2
0dbfs = 1

giSine ftgen 0, 0, 4096, 10, 1

instr 1
  iFreq = cpsmidinn(p4)
  iAmp  = (p5 > 0 ? p5 : 0.25)
  kEnv  linsegr 0, 0.02, 1, p3 - 0.04, 0.8, 0.02, 0
  kIdx  line 6, p3, 2
  aSig  foscili kEnv * iAmp, iFreq, 1, 2.4, kIdx, giSine
  out(aSig, aSig)
endin
</CsInstruments>
<CsScore>
i 1 0.00 0.45 60 0.22
i 1 0.45 0.45 64 0.22
i 1 0.90 0.45 67 0.22
i 1 1.35 0.45 72 0.24
i 1 2.50 1.50 60 0.18
i 1 2.50 1.50 64 0.16
i 1 2.50 1.50 67 0.14
</CsScore>
</CsoundSynthesizer>
```

For FM bells: copy the FM bell instr 1 from demo-score rules. `foscili` takes six args `(xamp, kcps, xcar, xmod, kndx, ifn)` — never two separate foscili lines.

For reverb send: use `gaRvbL` / `gaRvbR` accumulators cleared in instr 99 — NEVER `chnmix`/`chnget`/`inch` for inter-instrument routing (that is Player-only).

Global reverb pattern (copy for FM piano + reverb requests):

```
gaRvbL init 0
gaRvbR init 0

instr 1
  ; voice …
  gaRvbL += aSig * 0.4
  gaRvbR += aSig * 0.4
  out(aSig, aSig)
endin

instr 99
  aWetL, aWetR reverbsc gaRvbL, gaRvbR, 0.88, 9000
  out(aWetL * 0.35, aWetR * 0.35)
  gaRvbL = 0
  gaRvbR = 0
endin
```

Score MUST include `i 99 0 <duration>` before note events.

# Csound 7 rules (CRITICAL)

Target runtime is Csound 7. Violating these produces broken or silent output.

1. ALWAYS `0dbfs = 1` in orchestra header
2. Use `cpsmidinn(p4)` for MIDI→Hz — `cpsmidi()` takes NO arguments
3. `expseg`/`expsegr` values must ALL be > 0 — use 0.001 minimum
4. `linseg`/`expseg` args alternate value,dur,...,value — ODD count
5. Prefer `out(aL, aR)` for stereo output (`outs` still works but `out()` is preferred)
6. New-style UDOs: `opcode Name(args):type` — no `xin`. Old-style: `opcode Name, a, ak` with `xin`/`xout`
7. `reverbsc` needs 4 inputs: `aL,aR reverbsc aInL,aInR,kFbk,kCut`
8. Clear global audio buses each k-cycle: `gaRvbL = 0` or `clear gaRvbL`
9. Cabbage widgets need matching `chnget` with `port` smoothing
10. For Cabbage MIDI instruments: `f0 z` score, `-+rtmidi=NULL -M0`, on-screen `keyboard` widget
