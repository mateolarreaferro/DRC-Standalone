# Recent Work — Web App Piano Keyboard

**Project:** Dr.C Standalone (`/Users/richardboulanger/Dr.C-Standalone`)

**Scope:** Fix upside-down / incorrect keyboard in exported web apps (Convert to → Web App)

---

## Problem

After **Convert to → Web App**, the on-screen keyboard was wrong:

- Not a proper piano layout (black keys misaligned)
- Visually upside down (black keys at the player-facing edge instead of the back)

The keyboard is **not** generated by the LLM. It is built deterministically in `src/renderer/lib/webHarness.ts` when the host wraps the orchestra CSD into standalone HTML.

---

## Root Cause

1. **Layout algorithm** — Black keys used fractional offset math (`offset * WHITE_W - 11`) that did not match the working patterns elsewhere in the project.
2. **Vertical anchoring** — Both white and black keys used `bottom: 0`. Shorter black keys therefore sat at the **front** (bottom of the container) instead of the **back** (top), which reads as an inverted piano.

Reference implementations that behave correctly:

- `src/renderer/components/player/PianoKeyboard.tsx` (Electron Player — SVG, `y=0`, keys grow downward)
- `src/renderer/assets/apps/fibonacci-fm.html` (data-driven `buildKeyboard()`, black key at `wc * KBD_W - 12`)

---

## Changes Made

**Single file modified:** `src/renderer/lib/webHarness.ts`

### 1. HTML layout

- Moved `#keyboard` **below** `#controls` (controls first, piano second).
- Added `#octaveLabels` row for C3 / C4 / C5 markers.

### 2. CSS (inlined `STYLES`)

- Key dimensions aligned with Player: 31×100px white, 20×62px black.
- **Flip fix:** keys anchored with `top: 0; bottom: auto` (matches `PianoKeyboard.tsx`).
- Rounded corners at bottom (player-facing edge); `border-top: none`.
- QWERTY bind letters only (no note names on keys).

### 3. Runtime `buildKeyboard()` (inlined `RUNTIME`)

- Replaced white/black loop + offset table with **data-driven** `PIANO_PATTERN` (interleaved C–B per octave).
- Black key X position: `whiteCount * WHITE_W - BLACK_SHIFT` (`BLACK_SHIFT = 12`), same idea as Fibonacci FM.
- Constants: 3 octaves, `PIANO_START_OCT = 3`, `WHITE_W = 32`.
- Octave label spans built in JS.

   - Rounded edge toward the player (bottom)
